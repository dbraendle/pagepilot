# Changelog

## [Unreleased]

## [0.2.1] - 2026-10-22

### Changed
- First npm release, staged via GitHub Actions Trusted Publishing
- Package now ships the CHANGELOG

## [0.2.0] - 2026-10-22

### Added
- `tabs` option: choose which tabs appear and in which order
- `languages` option: turn off all language features for single-language
  sites (the circle then opens the full panel; the SEO check skips hreflang)
- Single-language demo page

## [0.1.0] - 2026-10-22

### Added
- Draggable panel in three sizes: circle, compact language bar, full panel with tabs
- Page tab: hreflang language tiles, hideable elements, instant language switch
  (Speculation Rules prefetch) with refresh, copy URL, uncached reload,
  environment switch
- SEO tab: meta checks, Google and social previews, heading outline, JSON-LD viewer
- Checks tab: gentle internal link check and image check
- Dev tab: breakpoint readout, grid overlay, component inspector with a
  "without" view, timings
- Cross-domain handoff of editor mode and settings
- Configuration for activation, theme, markets, environments, hideables and components
